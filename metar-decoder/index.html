METAR Decoder

A METAR (METeorological Aerodrome Report) is an “aviation routine weather report” used by pilots to observe airport weather conditions. Use this tool to translate a coded METAR into plain English.

Paste a complete METAR into the text box, then select Decode METAR. No METAR handy? Select Load sample to see it work.

  • Text M [Airport Code] to 358-782 (FLTSVC = Flight Service) to get latest METAR report (e.g., KGTU).
  • Look up an airport’s International Civil Aviation Organization (ICAO) code here: airnav.com/airports.
  • Look up an airport’s METAR here: aviationweather.gov.
References:
  • METAR element names: Federal Aviation Administration (FAA) Order JO 7900.5E, Surface Weather Observing (PDF)
  • METAR decoding key: Aeronautical Information Manual (AIM) Paragraph 7-1-28, Key to Aerodrome Forecast (TAF) and Aviation Routine Weather Report (METAR)
  • METAR element explanations: AIM Paragraph 7-1-29, International Civil Aviation Organization (ICAO) Weather Formats
